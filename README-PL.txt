ASHBOUND — instrukcja publikacji

PLIKI
Archiwum zawiera index.html (gra), manifest.webmanifest (instalacja PWA), sw.js (tryb offline po pierwszym uruchomieniu) oraz ikony aplikacji.

PUBLIKACJA W TWOIM REPOZYTORIUM
1. Otwórz https://github.com/hipotericstudio/ASHBOUND
2. Wybierz Add file → Upload files.
3. Rozpakuj archiwum i wgraj wszystkie pliki znajdujące się w środku bezpośrednio do głównego katalogu repozytorium (nie wgrywaj samego ZIP-a).
4. Kliknij Commit changes.
5. Otwórz Settings → Pages.
6. W Build and deployment wybierz Deploy from a branch.
7. Wybierz branch main oraz folder /(root), a następnie Save.
8. Po zakończeniu publikacji gra będzie dostępna pod adresem:
   https://hipotericstudio.github.io/ASHBOUND/

IPHONE / IPAD
Otwórz powyższy adres w Safari → Udostępnij → Dodaj do ekranu początkowego.

UWAGI
Gra działa w przeglądarce na komputerze i urządzeniach dotykowych. Najwygodniej grać na telefonie w orientacji poziomej. PWA wymaga HTTPS. Service worker buforuje pliki po pierwszym wejściu. Rekord i statystyki profilu zapisują się lokalnie w przeglądarce; postęp nie synchronizuje się pomiędzy urządzeniami i przerwany run nie jest odtwarzany.
